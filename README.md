# Мой день — Web App

Красивый статический трекер задач и привычек для GitHub Pages.

Возможности: задачи с датой, временем и приоритетом; добавление/редактирование/удаление; привычки; календарь; проценты; статистика; сохранение в браузере; PWA.

## GitHub Pages
1. Создайте репозиторий.
2. Загрузите файлы из этой папки в корень.
3. Settings → Pages → Deploy from a branch → main → / (root).
4. Откройте выданную ссылку на телефоне.
