# Habitly — яркий трекер привычек

Статическое web-приложение для GitHub Pages.

## Главное
- Только привычки — без отдельного типа задач.
- Можно самому добавлять любое количество привычек.
- Редактирование и удаление.
- Иконка и время для каждой привычки.
- Отметка выполнения каждый день.
- Дни недели в шапке.
- Календарь месяца с цветным прогрессом.
- Процент дня, средний прогресс и статистика.
- Данные сохраняются в браузере.
- PWA для добавления на главный экран телефона.

Загрузка: поместите все файлы в корень GitHub-репозитория и включите Settings → Pages → Deploy from branch → main → root.
